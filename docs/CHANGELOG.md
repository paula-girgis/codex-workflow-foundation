# Changelog

## 0.3.0 — scoped project lessons (local release)

- Added compact evidence-based lesson capture, targeted lookup, stale/contradictory knowledge handling and reviewed promotion guidance. No database, automatic retrieval, global instructions or state-schema change.
- Adoption creates an empty project-owned lesson record when absent and includes it in a new state's portable inventory. Existing lessons survive adoption and managed updates; older projects add the clean record explicitly when needed.
- Foundation maintenance examples remain private development history; clean templates never inherit incidents, approvals or completed work. Focused preservation/portability checks accompany the helper change.
- Local changes are prepared for review; prior releases and local Playwright work are preserved. Publishing, deployment and external services remain separate actions.

## 0.2.0 — optional repeatable web testing (local release)

- Added an explicit Playwright Test module: adaptable configuration/journey templates, activation/debugging/retention guidance and an inactive web CI template. Recommended for new web projects needing repeatable browser verification; suitable existing runners remain valid.
- Pilot-local pinned Playwright/Chromium verification is separate from the reusable templates; adoption/update only copy reference files and never install dependencies or browsers.
- Web increment/release gates identify tested inputs, failure diagnostics and review-only visual baselines. Browser mobile emulation is not native testing. Playwright MCP is not required.
- Prior releases are preserved. No commit, push, remote CI, deployment or published release is part of this local addition.
